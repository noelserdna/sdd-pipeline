## DESIGN-TOKENS JSON Schema

`ux/DESIGN-TOKENS.json` follows the W3C Design Tokens Community Group format: every token is an object with `$value` and `$type` (`color`, `dimension`, `fontFamily`, `fontWeight`, `number`, `duration`, `cubicBezier`, `shadow`…); groups nest by name; aliases use `{group.token}`. Primitives hold raw values; semantic tokens per theme alias primitives, so a theme switch only swaps the `theme-*` group.

```json
{
  "$description": "Generated by sdd-ux-designer on {ISO-8601}",
  "color": {
    "blue":  { "500": { "$type": "color", "$value": "#3B82F6" }, "400": { "$type": "color", "$value": "#60A5FA" } },
    "slate": { "50":  { "$type": "color", "$value": "#F8FAFC" }, "900": { "$type": "color", "$value": "#0F172A" } }
  },
  "theme-light": {
    "color": {
      "primary":    { "$type": "color", "$value": "{color.blue.500}" },
      "surface":    { "$type": "color", "$value": "{color.slate.50}" },
      "on-surface": { "$type": "color", "$value": "{color.slate.900}" }
    }
  },
  "theme-dark": {
    "color": {
      "primary":    { "$type": "color", "$value": "{color.blue.400}" },
      "surface":    { "$type": "color", "$value": "{color.slate.900}" },
      "on-surface": { "$type": "color", "$value": "{color.slate.50}" }
    }
  },
  "spacing": { "1": { "$type": "dimension", "$value": "0.25rem" }, "4": { "$type": "dimension", "$value": "1rem" } },
  "font": {
    "family": { "sans": { "$type": "fontFamily", "$value": ["Inter", "system-ui", "sans-serif"] } },
    "size":   { "base": { "$type": "dimension", "$value": "1rem" } },
    "weight": { "bold": { "$type": "fontWeight", "$value": 700 } }
  },
  "radius":     { "md": { "$type": "dimension", "$value": "0.5rem" } },
  "breakpoint": { "md": { "$type": "dimension", "$value": "768px" } },
  "target":     { "min": { "$type": "dimension", "$value": "24px", "$description": "WCAG 2.2 SC 2.5.8" } },
  "duration":   { "normal": { "$type": "duration", "$value": "200ms" } },
  "z-index":    { "modal": { "$type": "number", "$value": 1050 } }
}
```

Rules: include every category the decisions in UI-DESIGN-SYSTEM.md name (scales above are abbreviated); semantic names (`color.primary`, `color.error`) over literal ones; color tokens used in text/UI pairs appear in the contrast table of ACCESSIBILITY-SPEC.md; themes beyond light/dark add another `theme-*` group with the same keys. The file is framework-agnostic — Style Dictionary and similar tools transform it; no CSS or config files are generated.
